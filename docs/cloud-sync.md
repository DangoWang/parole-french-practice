# MongoDB Atlas + Vercel 云同步

这是个人使用的一份学习空间：以随机同步密钥鉴权，没有公开注册或多用户账号系统。所有持有同一密钥的设备访问同一份记录。数据库密码仅存 Vercel 环境变量；OpenAI Key 仍在每个设备的浏览器里。

## 部署

1. 在 Vercel 导入 GitHub 仓库 `DangoWang/parole-french-practice`，Root Directory 保持仓库根目录，Framework Preset 选 Other。项目的 `vercel.json` 已配置 `dist` 静态输出、`api/sync.js` 后端和 Oregon `pdx1` 区域。
2. 在 Environment Variables 中添加下面的值，至少勾选 Production。不要使用任何前端公开变量前缀。环境变量改动后重新部署才生效。

| 名称 | 值 |
| --- | --- |
| `MONGODB_URI` | Atlas 的连接字符串，替换用户名和密码；特殊字符需要 URL 编码 |
| `MONGODB_DB` | `parole` |
| `PAROLE_SYNC_KEY` | 密码管理器生成的至少 32 字符随机密钥，独立于 MongoDB 密码 |
| `ALLOWED_ORIGINS` | `https://parole-tcf-practice.alanyoyo.chatgpt.site`；其他允许的网页来源以英文逗号分隔 |

3. Atlas 数据库用户仅授予 `parole` 数据库的 `readWrite` 权限。数据库/collection 会在首次上传时自动创建。
4. Atlas Network Access 必须允许 Vercel 函数的出口网络；只添加个人电脑 IP 不足以让云端连接。免费 Vercel 默认没有固定出口 IP。个人项目若采用 `0.0.0.0/0`，意味着允许任意 IP 尝试连接数据库，必须保留独立强密码和最小数据库权限；它不等于免认证。需要严格 IP 限制时应改用固定出口网络方案。不要将数据库凭据填进网页。
5. 部署后，在原来的 Parole 网站「学习设置与备份 → 云同步」输入 Vercel 的 HTTPS 项目网址和 `PAROLE_SYNC_KEY`，保存并连接。原网站可继续使用；不必迁移到 Vercel 的前端网址。
6. 第一次先在已有完整记录的浏览器操作并导出学习备份。云端为空时上传本机记录；云端与本机不同时先暂停，显示两边练习次数供选择。新设备选择「使用云端记录」。

## 同步与恢复

- 本机修改后延迟 4 秒同步；打开的页面每分钟检查一次，联网后重试。关闭网页不会在后台继续上传，下次打开会补传。离开前可以点击「立即同步」查看状态。
- 上传句集、表达、标签、笔记、练习历史、评分、复习计划、目标和提醒时间。草稿、通知去重标记、录音、AI 反馈与密钥不上传。
- 原子版本比较阻止旧设备覆盖新数据。两端都修改时不会自动合并；用户选择一份作为当前记录，替换前下载另一份标准学习备份，可用现有导入功能恢复。
- 自动下载云端记录前，还会在本机保存 `parole.before-cloud.v1` 恢复副本，可以从设置下载。恢复副本只有上一份；重要备份请自行导出文件。
- 正在输入句子时延后自动应用云端记录，避免丢失输入。
- 断开只删除当前浏览器的同步凭据与同步标记，不删除本机或云端学习记录。修改后端同步密钥可撤销旧密钥，再让各设备重新连接。
- 同步密钥保存在 localStorage，没有加密，只在可信设备保存。不要分享该密钥。
- 单次同步限制 3 MB，超过时保留本机数据并提示导出备份，不截断历史。数据规模增长后需要分页/增量存储。

## 验证

`node --test tests/sync.test.cjs` 测试鉴权、来源限制、无效输入、字段白名单、并发版本冲突和客户端上传/下载。测试使用内存数据库替身；实际 Atlas 连接与 Vercel 部署需在配置真实环境变量后验收。

后端只提供 `/api/sync` 的 GET / PUT 接口，不提供公开数据库查询功能。所有数据库异常均转为固定提示，不返回连接字符串或密码。
